# Login Next.js + Supabase

Uma tela de autenticação moderna e segura utilizando App Router do Next.js, Server Actions, Tailwind CSS e Supabase.

## 🚀 Como Executar o Projeto

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Configure as variáveis de ambiente:**
   - Duplique o arquivo `.env.example` e renomeie-o para `.env.local`.
   - Adicione suas credenciais do projeto Supabase.

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
